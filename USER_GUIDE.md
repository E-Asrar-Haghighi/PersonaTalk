# PersonaTalk User Guide

## Everyday flow

1. Pick a persona from the right panel or create a new one.
2. Start a chat from the left sidebar.
3. Talk by typing in the center panel or use `Push to talk`.
4. Switch between `text`, `voice`, and `mixed` modes as needed.
5. Reopen previous chats from the history list or search by title/message content.

## Persona behavior

- The right panel controls the active persona name, system prompt, temperature, and voice preference.
- Saving updates the reusable persona preset.
- During a conversation, the current right-panel settings affect the next turn you send.
- Old conversations keep the persona snapshot that was saved in that chat, even if the original persona changes later.

## Voice behavior

- Voice input uses push-to-talk recording from your browser microphone.
- Browser audio is converted to WAV before upload so the local speech stack receives a stable input format.
- Transcripts are stored as text messages in the conversation history.
- Assistant replies can also include an audio response.
- If a provider fails, the app returns a readable error instead of silently failing.
